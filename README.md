# Портфолио — Data Science

Учебные и самостоятельные проекты по анализу данных и машинному обучению.
Студент прикладной математики; курс «Специалист по Data Science» проходится
самостоятельно, каждый проект доводится до состояния, в котором его можно
прочитать и понять без автора.

## Проекты

| № | Проект | Задача | Инструменты | Результат |
|---|--------|--------|-------------|-----------|
| 1 | [Рекомендация тарифов](01-tariff-recommendation/) | Бинарная классификация: подобрать клиенту мобильного оператора подходящий тариф по его поведению за месяц | pandas, scikit-learn | accuracy 0,818 на тестовой выборке против 0,694 у константной модели |
| 2 | [Отток клиентов банка](02-bank-churn/) | Бинарная классификация с перекосом классов (20/80): предсказать уход клиента, чтобы кампания удержания работала адресно | pandas, scikit-learn, Pipeline | F1 0,644 на тестовой выборке против 0,338 у константной модели; порог подобран по валидации |

## Как читать

В каждой папке — `README.md` с постановкой задачи и выводами, и ноутбук
с кодом. README рассчитан на чтение без запуска кода: результаты и выводы
приведены в тексте.
